# Changelog

## Frontend refinement

- Reworked typography, page spacing, focus states and the shared navy, slate, teal and blue palette.

- Compressed the overview and surfaced six audited KPIs with units and context. Added a conceptual energy-flow schematic with a compact text layout for narrow screens.
